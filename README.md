# 🎮 Cyberpunk Tic-Tac-Toe

A futuristic Tic-Tac-Toe experience built with HTML, CSS, and JavaScript, featuring immersive neon aesthetics, smooth animations, achievement tracking, and real-time player statistics.

---

## ✨ Features

### 🎯 Core Gameplay

* Classic Tic-Tac-Toe mechanics
* Two-player local multiplayer
* Instant win and draw detection
* Interactive game board
* Quick game reset functionality

### 🌈 Cyberpunk Visual Design

* Neon-glow inspired interface
* Futuristic cyberpunk theme
* Smooth hover and click animations
* Dynamic winning-cell highlights
* Responsive layout across devices
* Vibrant visual feedback for every move

### 🏆 Achievement System

Unlock achievements as you progress:

* 🥇 **First Win** — Secure your first victory
* ⚡ **Cyber Champion** — Build a record of wins
* 🔥 **Unstoppable** — Maintain a winning streak
* 🤖 **Matrix Master** — Become the ultimate champion

### 📊 Player Statistics

Monitor your performance in real time:

* Games Played
* Wins
* Losses
* Draws
* Win Rate
* Achievement Progress

### 🎨 User Experience

* Modern futuristic UI
* Smooth transitions and effects
* Real-time game status updates
* Mobile-friendly design
* Fast and intuitive gameplay

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns selecting a cell.
3. Align three symbols in a row:

   * Horizontally
   * Vertically
   * Diagonally
4. Win the match and unlock achievements.
5. Track your statistics and improve your win rate.
